https://www.exploit-db.com/exploits/17491

https://www.exploit-db.com/exploits/16320

https://www.exploit-db.com/exploits/13853

Задание 2 
Сравнение режимов сканирования Nmap.
В ходе работы были проведены сканирования в четырех режимах, трафик которых записан в Wireshark.
1. SYN-сканирование (-sS):
Трафик: Отправляется TCP-пакет с флагом SYN.
Ответ сервера: Если порт открыт, сервер отвечает SYN-ACK (после чего сканер отправляет RST для разрыва). На закрытые порты сервер отвечает RST.
2. FIN (-sF) и Xmas (-sX) сканирования:
Трафик: Отправляются TCP-пакеты с нестандартной комбинацией флагов (только FIN для FIN-сканирования, либо FIN+PSH+URG для Xmas). В Wireshark видно, что эти пакеты не инициируют соединение.
Ответ сервера: Если порт открыт, сервер полностью игнорирует пакет (в Wireshark тишина). Если порт закрыт, сервер сбрасывает соединение пакетом RST, ACK. Это работает благодаря логике стека TCP по RFC 793.
3. UDP-сканирование (-sU):
Трафик: Отправляются UDP-пакеты на разные порты.
Ответ сервера: Если порт закрыт, сервер присылает ICMP-сообщение Destination unreachable (Port unreachable) (видно на скриншоте). Если порт открыт, служба может ответить UDP-пакетом, либо проигнорировать запрос (тогда Nmap помечает порт как open|filtered).
